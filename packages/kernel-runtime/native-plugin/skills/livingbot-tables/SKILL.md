# 表格与数据

> 方法说明：本方法按既有办公/创作技能规范改写（规范改编），工具契约以本插件注册的原生工具为准。


先检查原始字段、表头、编码、数据类型、缺失值和单位，保留输入原件。
CSV 中的编号、前导零、日期和长数字不得未经确认转为数值。
合并前明确关联键、重复记录和未匹配项；缺失值与零分开处理。

使用当前可用的表格工具编辑工作簿，保留未涉及的工作表、公式、样式和命名范围。

## Excel 工作簿

本方法带一个真实的工作簿脚本 `scripts/xlsx-workbook.mjs`（依赖工作簿库 exceljs）。
不要自己拼 XML 或把 CSV 改扩展名当作工作簿。

先用 `--inspect` 读出实际工作表、单元格、公式和存储结果，确认字段与要改的位置：
`node scripts/xlsx-workbook.mjs --input 源.xlsx --inspect`。

再把改动写成 JSON，只列要改的单元格与要新增的汇总表；汇总行的单元格可以是值，
也可以写成 `{"formula":"SUMIF(明细!A3:A6,\"华东\",明细!D3:D6)"}` 让工作簿自己算：
```json
{"changes":[{"sheet":"明细","cell":"F2","formula":"D2*E2","result":963.96}],
 "addSheets":[{"name":"汇总","rows":[["区域","金额合计"],["华东",{"formula":"SUMIF(...)"}]]}]}
```
然后生成新工作簿并交付它：
`node scripts/xlsx-workbook.mjs --input 源.xlsx --output 结果.xlsx --ops 改动.json`。
输出必须是还不存在的新文件名：输出等于源文件或已存在时会直接拒绝（`output-is-source`
/ `output-exists`），不会覆盖源工作簿或任何已有文件；换个名字再试。

源文件保持原字节；未列出的工作表、单元格、公式与数字格式保持读入时的样子。
脚本输出一行 JSON 报告实际改了哪些单元格、新增了哪些工作表，据此核对，
需要时对新文件再跑一次 `--inspect` 确认内容，再用 livingbot_deliver_file 交付。
脚本报 `workbook-tool-unavailable` 时说明没有工作簿读写能力，改交付 CSV/TSV 并说明真实格式。
图表、数据透视表、宏与部分条件格式不在保留范围内，交付前如实说明这一点。
计算使用可复查的公式或脚本，不凭语言估算结果。

记录数据来源、观察期间、计量单位和关键变换。核对行数、去重/合并结果、
关键汇总和代表性明细；不能用猜测补齐未知数据。按用户所需提供结果表，
必要时另附异常行或未匹配清单，避免把冗长原始数据塞进聊天。
保存到任务或项目目录，再用 livingbot_deliver_file 交付实际文件。

## 写入与核对

修改工作簿后必须重新打开输出文件核对：`xlsx-workbook.mjs` 会回读并返回
`verified: true`，或返回 `read-back-mismatch` 并列出不一致的单元格。看到
`read-back-mismatch` 时不要说已完成——文件已经写出，但内容与请求不符，需要按列出的
差异修正后重新输出到新文件名。表格的预览、放大和排序只是查看，不是交付物；
交付的是实际写出的工作簿文件。

导入 CSV 前先确认编码：按 UTF-8 解码失败时很可能是 GBK/GB18030（Excel 中文默认），
先转成 UTF-8 副本再读写，不要事后修补乱码。逐列确认类型，类型不明时按文本处理并说明。

## 输入检查

先看表头、编码、分隔符、行列数、单位、缺失值与异常值；编号、前导零、长数字和日期
默认按文本处理，未确认前不转成数值。
多表合并先确认关联键唯一，重复键与未匹配行单独列出，不要把未匹配项静默丢弃。
区分“零”和“空”：空是没记录，零是记录为零。

## 步骤

1. 读入并回读：读完后打印行列数与前三行，确认没有错列、错编码。
2. 变换：每一步单独可复现，记录公式或脚本，不用语言估算数值。
3. 核对：行数守恒、关键汇总、抽样明细三方对齐；差异必须解释。
4. 交付：结果表 + 异常清单 + 变换说明。

## 失败边界

- 工作簿脚本报 `workbook-tool-unavailable` 时，改交付 CSV/TSV 并说明真实格式，不伪造成 xlsx。
- 输出文件名已存在或等于源文件时脚本会拒绝：换新名字，不覆盖。
- 图表、透视表、宏和条件格式不在保留范围，交付前说明。

## 不做

- 不擅自删行、改列名、合并单元格来“让表好看”。
- 不把 CSV 改扩展名当工作簿；不拼 XML。
- 不在未确认口径时给出汇总结论。
