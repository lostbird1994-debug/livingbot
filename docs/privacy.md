# 自托管数据与隐私说明

LivingBot 是可自行运行的开源软件。本说明描述自托管使用时的数据边界；具体部署的运营者应提供与其实际配置相符的隐私政策，并通过服务配置指定政策链接。

- 聊天、任务、附件和执行记录由部署配置所指定的数据存储保存。代码工作区迁移不自动迁移这些数据。
- 运行任务会将必要上下文交给所配置的模型、运行环境或外部应用。数据处理范围取决于启用的提供商及工具，需同时查看相应服务的隐私条款。
- Bot 使用外部连接或本机工具时，可能读取和处理用户授权的文件；不要把私密资料、凭据或真实运行日志提交到公共仓库。
- 本项目不代表、运营或承接历史上游的云服务。上游网站政策不自动适用于本项目的自托管部署。
- 备份、保留期、访问控制、日志与数据删除由具体部署负责设置和验证。不要把源码更新或构建当作用户数据清理流程。
