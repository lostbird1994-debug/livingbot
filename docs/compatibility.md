# 命名与兼容约定

当前产品和工作区包使用 LivingBot、`@livingbot/*`。源文件类型名称、产品文案及当前项目说明保持一致。

以下旧标识仍承担现有安装的兼容作用，不能只为文本清理直接替换：

| 范围 | 保留原因 |
| --- | --- |
| 已部署的环境变量与配置键 | 现有服务、部署文件和外部调用者仍使用它们 |
| OpenClaw 扩展 ID、工具名、会话格式及网关方法 | 已安装扩展、历史执行记录和恢复逻辑需要匹配 |
| HTTP 请求头、Cookie、深链与 IPC 通道 | 服务端、已有桌面客户端和登录流程需要兼容 |
| 应用 ID、内部 Keychain 身份与用户资料目录 | 避免新建空资料库、丢失登录状态或自动迁移用户数据 |
| 数据库角色、容器和原生服务标识 | 属于运行环境接口，重命名需要独立迁移方案 |
| 历史署名、许可及上游文档 | 保留真实来源与原始法律说明 |

上述部分是兼容接口，不作为新功能命名的模板。新功能应使用当前名称；需要迁移旧接口时，先提供别名或版本兼容，再验证恢复路径。

代码目录迁移不包含数据库、Bot 工作区或附件迁移。任何正式资料迁移必须单独备份和验收，不在启动或构建中自动处理。
