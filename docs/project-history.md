# 项目起源与发展

LivingBot 由开源项目 [Rakazo](https://github.com/elie222/rakazo) 发展而来。上游提供了持久 Bot、跨平台聊天界面、自托管服务以及可扩展运行环境等基础。本项目保留其原始许可与署名，作为独立分支持续维护。

## 演进方向

1. **基础适配**：将模型、工作区、文件及外部应用连接用于个人工作流，并接入本机执行环境。
2. **独立维护**：建立独立仓库和版本维护流程，停用上游自动安装与覆盖更新。
3. **任务并行**：增加同一 Bot 下的独立任务会话、任务历史、结果回执与关闭后恢复入口。
4. **执行稳定性**：采用每轮独立原生会话，改善旧会话不确定状态阻塞后续对话的问题；补充历史摘要、图片上下文、分页恢复和停止重试。
5. **上下文与调度**：让例行任务继承对话结论，统一摘要策略，区分运行状态展示与资源准入，并为摘要失败增加分阶段重试。
6. **项目整理**：统一当前产品名称与工作区包命名，建立清晰的代码、公共文档和本机资料边界。

以上描述项目方向和已纳入维护的能力，并不表示所有平台均完成正式环境验收。具体行为以代码、测试与发布说明为准。

## 继承与独立性

- 继承上游开源基础，不把上游历史版本重新宣称为本项目发布。
- 旧版协议标识、环境变量、应用身份和数据目录在需要兼容时继续保留；参阅[兼容约定](compatibility.md)。
- 历史文档归档在 `docs/reference/`，不应直接按其中的上游下载、云服务和发布步骤部署本项目。
- 当前项目不建立或暗示对上游网站、云服务、商店版本或安全邮箱的所有权。
